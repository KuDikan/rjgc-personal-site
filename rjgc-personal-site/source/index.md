## 这个站点是什么

这是一个用 [Hexo](https://hexo.io/zh-cn/) 与 [ShokaX](https://docs.shokax.kaitaku.xyz/) 构建的个人网站，
部署在 Cloudflare Workers 上，源码与构建流程全部托管在 GitHub。

站点包含七个分区：

| 分区 | 说明 |
|---|---|
| [关于我](/about/) | 基本信息与技能方向 |
| [博客](/categories/) | 按时间倒序的文章，含归档与标签 |
| [RSS 订阅](/rss/) | 本站对外发布的订阅源，以及站内聚合的外部订阅 |
| [Research Papers](/papers/) | 自动收集的领域最新论文 |
| [Wiki](/wiki/) | 个人知识沉淀，支持双向链接 |
| [状态面板](/status/) | 构建时间、页面数与各项数据统计 |
