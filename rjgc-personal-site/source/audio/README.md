# 音乐播放器音源

把音频文件放进**本目录**（`source/audio/`），然后执行 `npm run music` 重新生成
`source/_data/music.json`，播放器就会收录这些曲目。

## 命名规则

用 `歌名-歌手.扩展名`，构建脚本会优先按此精确匹配网易云歌单里的曲目：

```
我不难过-孙燕姿.mp3
如何给需求分级-未知.mp3      # 只有歌名也可匹配
```

匹配顺序：`歌名-歌手` → `歌名` → 按文件顺序兜底。
建议按上面命名，能避免兜底匹配把曲子配错。

支持格式：`.mp3` `.m4a` `.aac` `.ogg` `.wav` `.flac`

## 为什么音频要自己提供

歌单元数据（歌名 / 歌手 / 专辑 / 时长 / 封面）来自网易云公开接口，可正常获取。
但**音频流拿不到**——网易云音频 CDN 对所有请求返回 403，
`/api/song/media` 接口也不再返回可播放地址。因此音频必须自备。

## 注意事项

- 本目录**不在** `source/_data/assets/` 里。那个目录必须保持扁平
  （主题的 images 生成器会逐文件 readFile，嵌套子目录会触发 EISDIR）。
- 单曲建议 3–8 MB。音频不进 Git LFS，首屏访问不会自动下载，
  但会占用部署体积（Cloudflare 单文件上限 25 MB）。
- 没有音频文件时播放器不会注入，构建日志会给出提示。
