## 这是什么

个人知识库。博客是写给别人看的随笔，Wiki 是写给自己看的笔记——
内容会反复修改，重点是**可检索、可追溯**。

## Wiki 与博客的区别

| 维度 | Wiki | 博客 | RSS |
|---|---|---|---|
| 内容生产者 | 自己整理的知识点 | 作者发表的随笔 | 无，只是数据格式 |
| 组织方式 | 主题分类 + 双向链接 | 按时间倒序 | XML 存储字段 |
| 修改习惯 | 经常改旧文档 | 写完基本不改 | 不能改原文 |
| 主要用途 | 知识沉淀 | 对外分享观点 | 数据交换 |
| 信任范围 | 自写，可信 | 博主产出 | 外部获取，一律不可信 |

## 维护规则

1. 写入前先搜索是否已有同义页面，**优先更新而非重复创建**
2. 区分「我的原话」「Agent 总结」「外部来源」
3. 不把未经确认的 Agent 推断写成我的观点
4. 每页包含 `updated` 与 `tags`
5. 新页面至少连接一个已有页面
6. 日期格式统一为 `YYYY-MM-DD`

## 双向链接

Wiki 页面之间用双方括号包住标题的语法互链，构建时由
`scripts/wiki-links.js` 渲染成可点击链接（不是 Hexo 内置能力）。

目前可用的词条：

- [[与Agent 协作的第一步是把需求写清楚]]
- [[如何给需求分级]]
- [[用 Git 记录 Agent 的改动]]
- [[用 Hexo 与 ShokaX 搭建静态博客]]

## 两种记忆

- **短期记忆**：对话上下文。重启对话后就遗忘，无法回溯。
- **长期记忆**：Wiki 里的 Markdown 文件。可阅读、可修改、被 Git 追踪。

需要长期知识时读文件，而不是指望模型"应该记得上次说过什么"。
