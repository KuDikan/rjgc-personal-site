## 这个面板想说明什么

Agent 会持续做很多事：抓取外部数据、生成页面、执行构建。
如果它失败了而你不知道，那这个自动化就是负资产。

所以面板上必须有：

- **最近一次构建时间** —— 判断看到的是不是最新内容
- **各项计数** —— 数据有没有被意外清空
- **校验结果** —— 数据结构是否还合法

## 可观测性的最小实现

日志至少要包含：

```text
时间 + 任务 + 输入摘要 + 执行动作 + 验证结果 + 错误 + run_id
```

但不要把Token、邮箱正文或 Webhook 密钥写进日志。

## 信任边界

本页所有数字来自本仓库的构建产物，不含任何外部输入。
外部数据（论文、RSS）的失败不会影响这里的计数——
脚本在失败时会保留上一次的数据，而不是写入空值。
